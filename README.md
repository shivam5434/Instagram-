# 📸 Instagram Frontend Clone

A **pure frontend clone of Instagram** built to replicate core feed interactions using **HTML, CSS, and JavaScript**.  
This project focuses on UI behavior and media interaction without any backend or authentication.

---

## 🌐 Live Demo

👉 **Vercel Deployment:**  
https://instagram-ruddy-six.vercel.app/

---

## 🚀 Features

- Instagram-style layout (Navbar + Feed)
- Single post with video
- Play / Pause video control
- Mute / Unmute audio
- Like / Unlike functionality
- Instant UI updates without page reload

---

## 🛠️ Tech Stack

- HTML5  
- CSS3 (Flexbox, modern layout techniques)  
- Vanilla JavaScript  

> Note: This is a frontend-only project. No backend, database, or API is used.
